# FreshAirIQ 0.8.1 – Settings UX redesign

- Rebuilt the settings navigation into five task-oriented groups instead of one long menu.
- Added short descriptions below main navigation choices for faster orientation on mobile.
- Room configuration now uses native Home Assistant collapsible sections: Room, Sensors & windows, Room size, Optional sensors.
- Room-specific settings remain on the native room entry and use shorter, clearer labels.
- Expert/model settings are separated from everyday settings.
- Reset actions are isolated under Maintenance to reduce accidental use.
- No calculation or learning logic was changed by this UX release.
