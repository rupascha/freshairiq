# FreshAirIQ 0.20.4.3 – Bewohnerprofile & persönliche Ansprache

FreshAirIQ kann Bewohner jetzt optional mit Namen kennen. Namen werden den Erwachsenen- bzw. Kinder-Trackern in derselben Reihenfolge zugeordnet; zusätzliche Namen dürfen Bewohner ohne eigenen Tracker abbilden.

Die Personal Context Engine verwendet einen Namen nur, wenn eine direkte Ansprache wirklich belastbar ist: Eine erwachsene Person muss eindeutig als einzige erwachsene Person zuhause erkannt werden. Sobald ein weiterer erwachsener Bewohner ungetrackt sein könnte, bleibt die Empfehlung neutral. Kindernamen werden nie für direkte Handlungsaufforderungen verwendet.

Die Personalisierung ist rein präsentativ. Aktion, Räume, Lüftungsdauer, Prognosen, Lernkoeffizienten und Sicherheitsgrenzen werden nicht verändert. Bewohnernamen werden nicht in die FreshAirIQ-Diagnostik exportiert.
