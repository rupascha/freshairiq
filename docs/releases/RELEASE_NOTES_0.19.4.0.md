# FreshAirIQ 0.19.4.0

- Dashboard-Einstellungen von statischem Kachel-Ein/Aus auf Informationspräferenzen umgestellt.
- Adaptive Hauptansicht respektiert Feuchte-, Temperatur-, Zeit-, Prognose-, Nacht-, Schimmel- sowie Energie/Kosten-Präferenzen.
- Neue Darstellungsoptionen für Branding, Hausprofil und IQ-Analyseleiste.
- Bestehende alte Kartenoptionen werden automatisch kompatibel übernommen.
- Sicherheitsrelevante Hauptentscheidung und Begründung bleiben unabhängig von Anzeigepräferenzen erhalten.
