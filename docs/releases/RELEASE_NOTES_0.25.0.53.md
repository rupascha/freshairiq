# FreshAirIQ 0.25.0.53

## Diagnostics & Support Foundation v1

- Privacy-sichere Support-Incident-Schicht ergänzt, ohne Einfluss auf Lüftungsentscheidungen.
- Stabile Support-Codes für Sensor-/Datenfehler, Runtime-Konfigurationsprobleme, Diagnostics-I/O und Decision-Invariant-Verletzungen.
- Deterministische Incident-Fingerprints für spätere installationsübergreifende Gruppierung gleicher Fehlerbilder.
- Deterministische Decision-Trace-IDs für reproduzierbare Supportfälle.
- Diagnostics-Schema auf v11 erweitert; bestehender Hub-Upload-v2-Vertrag bleibt kompatibel.
- Support-Metadaten enthalten keine Entity-IDs, Raumnamen oder Freitexte.
