# FreshAirIQ 0.25.4.16

Hotfix auf Basis 0.25.4.15.

- Bewohnernamen werden mit einem konkreten Komma-/Tracker-Beispiel erklärt.
- Kontaktbezogene Öffnungsverzögerung und Himmelsrichtung sind in die jeweilige Fenster-/Tür-Seite integriert.
- Reihenfolge dort: Referenztemperatur/-feuchte, Öffnungsverzögerung, Himmelsrichtung, Rollo/Jalousie, Tür-Sonderfall.
- Separate Raum-Menüpunkte für Himmelsrichtung und Öffnungsverzögerung entfallen; bestehende Datenkeys und Runtime-Semantik bleiben unverändert.
