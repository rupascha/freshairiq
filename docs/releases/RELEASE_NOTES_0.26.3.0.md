# FreshAirIQ 0.26.3.0

## Diagnostics only with your consent
Automatic, pseudonymised diagnostics are now sent **only after an admin agrees**. After updating, the dashboard card asks once: "Diagnosen teilen?". Until you decide, nothing is uploaded automatically. You can change the decision at any time in the dashboard settings (Privacy & diagnostics) or under Devices & services → FreshAirIQ → Configure.

The settings now also state the real destination (diagnostics.freshairiq.com, HTTPS) and what stays in the data.

- Hassfest and HACS validation in CI.
- Everything from 0.26.2.14: Rooms tile fix, slim plain-language goal display, larger touch targets, render error boundary.
