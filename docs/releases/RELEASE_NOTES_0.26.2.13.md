# FreshAirIQ 0.26.2.13

Public UI recovery release.

The Rooms navigation is restored from the known public v0.26.2.6 implementation instead of another new event model. In addition, the visible RÄUME/ROOMS scope pill opens the same existing room overview. Goal summary chips keep reached/total and display the longest remaining ETA; while the learned trend ETA is not yet available, the current recommended duration is used as fallback. The unwanted top edge on compact room rows is removed.

The backend/config-flow fixes from the later hotfixes remain in place.
