# FreshAirIQ 0.9.4.8 — room overview redesign

- The room overview now concentrates on stable room facts instead of ventilation actions.
- Each room card keeps room climate, mould risk, learning status and configured room properties, and adds the total water-vapour amount in the room air in mL.
- Removed from room cards: action labels such as Wait/Ventilate, removable potential/live balance, 5-minute forecast, recommendation reasons and last-measurement banner.
- Room details now show the last measurement explicitly with its plausibility result and retain the last learning measurement/diagnosis.
- No calculation, learning, forecast, recommendation or configuration logic was changed.
