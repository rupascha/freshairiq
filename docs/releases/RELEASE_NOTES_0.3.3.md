# FreshAirIQ 0.3.3

The FreshAirIQ dashboard now uses the official FreshAirIQ house / airflow / leaf logo instead of a generic MDI icon.

Copy `www/freshairiq/freshairiq-icon.png` to `/config/www/freshairiq/freshairiq-icon.png`.
Home Assistant then serves it as `/local/freshairiq/freshairiq-icon.png`.
