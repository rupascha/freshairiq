# FreshAirIQ 0.20.4.0 – Prognoseanzeige erst bei aktiver Lüftung

## Änderung
- Die Kachel **„BEI LÜFTUNG · <Horizont> MIN“** wird vor Beginn einer Lüftung nicht mehr angezeigt.
- Im Bereich **„IQ AKTIV“** wird der Prognosehorizont vor Lüftungsbeginn ebenfalls nicht mehr eingeblendet.
- Sobald eine Lüftung aktiv ist, bleibt die vorhandene Live-Prognose **„WEITERE <Horizont> MIN“** vollständig erhalten.

## Unverändert
- Prognoseberechnung, Lernlogik, Validierung, Backtesting, Entscheidungslogik und alle Backend-Werte bleiben unverändert.
- Nachtprognose, „Jetzt entfernbar“, Schimmelanzeige und alle übrigen Entscheidungselemente bleiben bestehen.
