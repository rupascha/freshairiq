# FreshAirIQ 0.8.2 — Korrektur 5.0

1. **Räume sortieren:** mobile-stabiler Positionsdialog ohne fragilen Reorder-Multiselect.
2. **Schimmelrisiko:** Hauptkachel öffnet eine vollständige Raumliste mit Risikostufe und Oberflächen-RH.
3. **Scrollen:** das Overlay selbst ist jetzt der einzige native vertikale Scroller; kein verschachtelter Dialog-Scroller mehr.
4. **Details:** enthält nur Haus-/IQ-Details, Statistiken, Lernmodell und zusätzlich das Ergebnis der letzten abgeschlossenen Lüftung.
5. **Räume:** eigene Schaltfläche neben Details öffnet die nach Bereichen sortierte Raumübersicht.
6. **Lüftungsschwelle:** die Haus-Empfehlung „Jetzt lüften“ wird nicht mehr durch einzelne hohe Raum-RH unterhalb der sichtbaren Hausschwelle ausgelöst.
