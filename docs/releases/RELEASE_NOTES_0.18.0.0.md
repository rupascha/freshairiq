# FreshAirIQ 0.18.0.0 – Intelligent Home Climate UI

- Neue zentrale Intelligence Card: die aktuelle Entscheidung trägt die relevanten Live- und Prognosewerte direkt in sich.
- Große Metrik-Kacheln der Hauptansicht entfernt; unten bleiben kompakt Details, Gäste und Räume.
- Branding erweitert um „Intelligent Home Climate“.
- Neuer „IQ AKTIV“-Bereich visualisiert echte ausgewertete Datenquellen, Optionen und Live-Abgleiche statt dekorativer Zufallstexte.
- Jede Kurzzeitprognose nennt den tatsächlich eingestellten Zeitraum (1–120 Minuten).
- Prognosezeitraum ist direkt in FreshAirIQ Einstellungen > Komfort & Luftqualität verfügbar.
- Derselbe Prognosezeitraum kann direkt in der Detailansicht geändert werden; beide Stellen steuern dieselbe zentrale Option.
- Bestehende Berechnungs-, Raum-, Lern-, Energie-, Pollen-, Querlüftungs- und Entscheidungslogik bleibt erhalten.
