# FreshAirIQ 0.25.0.51

## Reliability Foundation v2

- Golden-Scenario-/Replay-Engine für stabile fachliche Empfehlungsverträge eingeführt.
- Sieben deterministische Kernfälle schützen Lüften, Nicht-Handeln, Sicherheits-Override, Sensorausfall, Pollen-Veto, laufende Lüftung und Schließen.
- Numerische Erwartungen verwenden nur explizite absolute Toleranzen; Quelltextzeilen werden nicht eingefroren.
- Golden Scenario Replay ist jetzt ein release-blockierendes Pflicht-Gate.
- Einzelne Szenarien können gezielt für Support und Fehler-Triage reproduziert werden.
- Golden-Fixtures enthalten keine personenbezogenen Installations-, Token- oder Bewohnerdaten.
