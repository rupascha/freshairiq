# FreshAirIQ 0.20.4.0

## Personal Context Engine v1

- Neue, strikt von der Physik getrennte Personalisierungsschicht für authentischere Empfehlungen.
- Neue Einstellungen: persönliche Empfehlungen, Temperaturempfinden, persönliche Priorität und Nachtfenster-Präferenz.
- Vorhandene Haushalts-/Anwesenheitsdaten und bereits gelerntes Empfehlungs-Folgeverhalten werden als Kontext genutzt.
- Verhaltenskontext wird erst nach mindestens fünf beobachteten Empfehlungschancen verwendet.
- Sicherheits-, Schimmel- und CO₂-Grenzen, Prognosen, Räume und empfohlene Dauer werden durch die Personalisierung niemals verändert.
- Dashboard und native Home-Assistant-Optionen verwenden weiterhin denselben Konfigurationsspeicher.
