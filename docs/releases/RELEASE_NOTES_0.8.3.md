# FreshAirIQ 0.8.3 — Raumbezogene Empfehlungen

- **Raum vor Haus:** Eine zu hohe Luftfeuchtigkeit, kritische Oberflächenfeuchte oder hoher CO₂-Wert kann eine eigene Raumempfehlung auslösen, auch wenn das gesamte Hauspotenzial noch unter der Hausschwelle liegt.
- **Konkrete Begründung:** FreshAirIQ nennt den tatsächlichen Auslöser mit Messwert und Grenzwert sowie die Feuchtedifferenz zur Außen-/Referenzluft.
- **Ungeeignete Außenluft:** Bei feuchterer oder zu wenig trockener Außenluft wird nicht pauschal zum Lüften geraten, sondern erklärt, warum Abwarten bzw. Nichtlüften sinnvoll ist.
- **Neuer Empfehlungsbereich:** Das Hauptdashboard zeigt raumbezogene Maßnahmen und mehrere Begründungszeilen deutlich lesbarer an.
- **Konsistente Texte:** Raumkarten, Detailansicht und Benachrichtigungen nutzen dieselben Empfehlungsgründe.
- **Hausschwelle bleibt getrennt:** Die sichtbare Haus-Lüftungsschwelle steuert weiterhin ausschließlich die allgemeine hausweite Empfehlung.
