# FreshAirIQ v0.25.4.10

## Settings centralization hotfix

- Devices & services → **Add room** is now an add-only quick setup with **Create new room** or **Import from Home Assistant**.
- Existing room subentries remain available for Home Assistant identity/entity grouping but no longer expose a separate FreshAirIQ reconfigure flow.
- Devices & services → FreshAirIQ → **Configure** is the single complete FreshAirIQ settings center, including residents and room management.
- The dashboard no longer exposes the duplicate FreshAirIQ settings gear; its card editor is presentation-only.
- Support keeps diagnostics export/send, feedback and email. Automatic diagnostics status is shown there, while its setting is changed in the central configuration.
