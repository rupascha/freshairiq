# FreshAirIQ 0.25.4.5

## Hotfix: kompakteres Lüftungsprotokoll (GitHub Issue #9)

- PDF-Lüftungsprotokoll von großen Einzelkarten auf kompakte, raumweise gruppierte Tabellen umgestellt.
- Eine abgeschlossene Lüftung entspricht einer Tabellenzeile.
- Spalten: Datum, Zeit, Dauer, Temperatur vorher/nachher, relative Luftfeuchte vorher/nachher, absolute Feuchte vorher/nachher, Feuchtebilanz und Empfehlung befolgt.
- Tabellenkopf und Raumbezeichnung werden bei Seitenumbrüchen wiederholt.
- Datenerfassung, lokale Speicherung, Filterung und Export-API bleiben unverändert.
