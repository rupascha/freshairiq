# FreshAirIQ v0.25.1.0 – AI-First Dashboard

## New dashboard experience
- Compact AI-first landing view focused on the single most relevant FreshAirIQ decision.
- Animated mascot communicates state without adding another data-heavy card.
- Automatic states for recommendation, active ventilation, warning and all-clear.
- Only rooms requiring attention are promoted on the landing view.
- Night, pollen and learning are compact drill-down entry points.
- Existing detailed views and calculation logic remain available and unchanged.
- Motion automatically stops when the operating system requests reduced motion.
