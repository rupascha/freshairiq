# FreshAirIQ 0.20.4.4 – Bewohnerprofile mit Raumzuordnung

## Neu

- Bewohnern können im Dashboard beliebig viele FreshAirIQ-Räume zugeordnet werden.
- Je Bewohner kann optional ein individuelles Temperaturempfinden gewählt werden: Haushaltsprofil, eher warm, ausgewogen oder eher kühl.
- Direkte Empfehlungen können bei eindeutig anwesenden Erwachsenen den zugeordneten Raum natürlich erwähnen.
- Bei Kindern verwendet FreshAirIQ die Raumzuordnung nur als Kontext und niemals als direkte Handlungsaufforderung.

## Sicherheitsgrenze

Die Bewohnerprofile sind reine Personal-Context-Daten. Sie verändern keine physikalische Berechnung, keine ausgewählten Räume, keine Lüftungsdauer, keine Prognose und keine CO₂-/Schimmel-Sicherheitsgrenze.

## Datenschutz

Namen, Bewohnerprofile und personalisierte Empfehlungstexte werden nicht in die exportierbaren FreshAirIQ-Diagnosedaten übernommen. Die Diagnose enthält weiterhin die technische Entscheidung ohne personenbezogene Präsentationsdaten.
