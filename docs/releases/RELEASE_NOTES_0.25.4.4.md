# FreshAirIQ 0.25.4.4

Hotfix für die Thermostat-/Temperaturziel-Erklärungen. Ein Thermostat/Klimagerät ist ausdrücklich freiwillig; Räume können ohne diese Entität gespeichert und betrieben werden. Bei Auswahl nutzt der Automatikmodus den letzten plausiblen Sollwert. Manuelle und Fallback-Zieltemperaturen bleiben alternative Quellen.
