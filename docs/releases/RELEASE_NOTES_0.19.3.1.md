# FreshAirIQ 0.19.3.1 — Hotfix

- Das große Details-Fenster zeigt „Letzte Lüftung“ nur noch als kompakte, anklickbare Kachel. Die vollständige Auswertung öffnet sich erst nach einem zweiten Tipp.
- Eine laufende Lüftung gilt erst nach 3 Sekunden durchgehend geschlossenem Kontakt als beendet. Ein kurzes versehentliches Schließen mit sofortigem Wiederöffnen beendet die Sitzung nicht und überschreibt dadurch nicht das letzte Lüftungsergebnis.
- Kontakt-Öffnungsverzögerungen werden bei einer bereits laufenden Sitzung nach einem kurzen Wiederöffnen nicht erneut als Startbedingung angewendet.
