# FreshAirIQ 0.25.0.49 – Sensorless Room Creation Hotfix

## Behoben
- Ein neuer Raum kann mit Name und direktem Raumvolumen (m³) gespeichert werden, obwohl noch keine Sensoren installiert sind.
- Solche Räume bleiben bis zur Sensorzuordnung von aktiven Berechnungen ausgeschlossen.
- Sobald eine Sensorkonfiguration begonnen wurde, gelten weiterhin die bestehenden Vollständigkeitsprüfungen.

## Umfang
Gezielter Hotfix auf Basis 0.25.0.48. Keine fachliche Änderung der Lüftungs-, Lern-, Diagnose- oder Prognoselogik.
