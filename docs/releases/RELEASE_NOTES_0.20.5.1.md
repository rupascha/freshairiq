# FreshAirIQ 0.20.5.1

Hotfix für die Dashboard-Konfiguration.

- Vollständige Dashboard-Darstellung ist wieder der Standard.
- Alle bisherigen Informationsbereiche können in der Kartenkonfiguration einzeln ein- oder ausgeblendet werden.
- Details-, Gäste- und Räume-Schaltflächen sind nun ebenfalls einzeln ausblendbar.
- Dadurch ist optional eine kompakte Ansicht möglich, in der praktisch nur die zentrale Empfehlung sichtbar bleibt.
- Berechnungs-, Prognose- und Empfehlungslogik aus 0.20.5.0 bleibt unverändert.
