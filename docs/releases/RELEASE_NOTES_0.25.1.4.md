# FreshAirIQ v0.25.1.4 – Dual Dashboard Hotfix

## Dashboard choice
- Adds a per-card dashboard selector: **Classic** or **FreshAirIQ IQ**.
- **Classic** preserves the information-rich v0.25.0.75 landing surface.
- **FreshAirIQ IQ** keeps the compact mascot/AI-first landing surface introduced in v0.25.1.x.
- Both variants use the same FreshAirIQ backend state, calculations, learning data, room configuration and detail views.
- Switching the dashboard style changes presentation only.

## German & English
- The new dashboard selector, description and choices are available in German and English according to the Home Assistant UI language.
- Future FreshAirIQ UI additions are required to ship with German and English copy together.

## Scope
No ventilation physics, recommendation thresholds, learning algorithms, diagnostics transport or room data were changed by this hotfix.
