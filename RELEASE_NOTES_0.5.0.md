# FreshAirIQ 0.5.0 — Integrated dashboard

FreshAirIQ now ships its own Home Assistant frontend.

- Add **FreshAirIQ Climate Intelligence** directly from the Community card picker.
- Create **FreshAirIQ Climate Dashboard** from Community dashboards on HA 2026.5+.
- No manual dashboard YAML is required.
- No Browser Mod or custom:button-card dependency is required.
- Rooms are read dynamically from FreshAirIQ.
