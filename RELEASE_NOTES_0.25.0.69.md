# FreshAirIQ 0.25.0.69 – Android Scroll & Onboarding Hotfix

- Android/WebView: Detail- und Unterfenster erhalten einen stabilen eigenen Scrollbereich.
- Navigation: Beim Zurückgehen wird die exakte Scrollposition des vorherigen Fensters wiederhergestellt; beim Schließen bleibt die Dashboard-Position erhalten.
- Feuchtequellen: Waschmaschine, Trockner und Bügelstation ergänzt (insbesondere für Wäscheraum-Konfigurationen).
- Diagnose-Onboarding: Installation wird sofort anonym registriert, Diagnose-/Geräteinformationen werden bei Neuinstallationen erst nach 30 Minuten übertragen.
- HACS: README ist jetzt versionsneutral und bleibt als dauerhafte Projektbeschreibung stabil; versionsbezogene Änderungen stehen ausschließlich in den Release Notes.
