# FreshAirIQ 0.25.0.68 — Public Beta

FreshAirIQ startet mit dieser Version in die öffentliche Beta.

FreshAirIQ ist eine Home-Assistant-Integration für intelligente, nachvollziehbare Lüftungsentscheidungen. Statt nur Luftfeuchtigkeit anzuzeigen, verbindet FreshAirIQ absolute Feuchte, Wassermenge in der Raumluft, Innen- und Außenklima, Raumvolumen, Fensterzustände, Wetter, Temperaturentwicklung, Anwesenheit und gelerntes Gebäudeverhalten zu einer konkreten Empfehlung:

**Warten → Lüften → Weiterlüften → Schließen.** Für einzelne Räume, Etagen oder das ganze Haus.

## Öffentliche Beta — Tester gesucht

Für die erste öffentliche Beta suchen wir rund **20 deutschsprachige Home-Assistant-Haushalte** aus Deutschland, Österreich und der Schweiz. Besonders wertvoll sind unterschiedliche Gebäude, Raumgrößen, Sensorhersteller, Lüftungsgewohnheiten sowie Android-, iOS- und Browser-Setups.

Hilfreiches Feedback betrifft insbesondere Ersteinrichtung, Verständlichkeit der Empfehlungen, Prognoseverhalten, Lernfortschritt, mobile Darstellung und ungewöhnliche Gebäudesituationen.

## In dieser Version
